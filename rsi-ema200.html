  1. Tap COPY below
  2. Open TradingView → Pine Editor
  3. Long-press → Select all, then backspace so the default template is gone
  4. Paste → Save → Add to chart

If COPY does nothing, tap SELECT ALL, then long-press inside the box and choose Copy. The box is read-only so nothing can be changed by accident.
